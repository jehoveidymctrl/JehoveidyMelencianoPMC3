## Compilar y ejecutar

```bash
make
./bin/cap7
./bin/cap8
```

Cada programa tiene un menú. En el capítulo 8 cada problema permite capturar los datos
o usar datos de ejemplo.

## Decisiones de interpretación

- **PS7.1 / PS7.2:** las posiciones se cuentan desde 1 (impares = 1.º, 3.º, 5.º…; pares = 2.º, 4.º…).
- **PS7.4:** el año de dos dígitos 00–49 se toma como 20xx y 50–99 como 19xx.
- **PS7.14:** la tabla del libro marca 8 palabras de longitud 7; al contarlas una por una hay 7
  (amargas, siempre, destino, Juvenal, todavía, acudido, urgente). El resto de la tabla coincide.
- **PS8.2:** los resultados se escriben como `América 0 - Puebla 2` (acepta `-` o `–`, sin importar
  mayúsculas ni acentos). La tabla se ordena por puntos, diferencia de goles y goles a favor.
- **PS8.3:** "extranjero" significa nacionalidad distinta de Colombia.
